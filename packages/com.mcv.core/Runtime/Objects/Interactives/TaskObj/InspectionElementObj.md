# Contract: InspectionElementObj

Role: measured component; stores the pairing of its own inspection points plus the expected reading of each pair as InspectionData, and tracks the actuation state.

Fields:
elementType:ElementType  [SerializeField] component type; also picks which terminal-pair table the pairing uses
inspectionData:InspectionData  [SerializeField] point pairing data (read-only at runtime, written in the Editor)
actuationSwitches:List<InspectionSwitchObj>  [SerializeField] parts that drive the actuation state; any pressed == actuated; empty = no actuation part
m_Actuated:bool  cached actuation state
IsActuated  read-only accessor
ActuationState  Normal / Actuated

Methods:
Awake()  base -> subscribe each switch's PressedChanged -> RefreshActuation
OnDestroy()  unsubscribe the switches -> base
OnActuationSwitchChanged(bool)  -> RefreshActuation
RefreshActuation()  any switch IsPressed sets m_Actuated true

Notes:
- The inspection points must be children of this object: the Editor scan and the "both probes on the same component" check both rely on that parent-child relation.
- The pairing table is generated by the inspector panel and is read-only at runtime.
- The actuation state is what makes the multimeter read the actuated group of a point pair, so a missing switch entry silently keeps the static reading.
