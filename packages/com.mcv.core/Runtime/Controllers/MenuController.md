Notes:

- Binding is by the `[RequireController(typeof(MenuController))]` attribute on MenuPanel; the name convention MenuPanel -> MenuController is only the fallback, so renaming one side requires touching the other.
- Plain C# class on GlobalControllerMgr's type table: created in DelayInit and kept for the app lifetime, so there is no Awake / OnDestroy and no scene instance (the old ControllerRoot instances are gone).
- Subscription discipline: anything registered in OnViewBound must clear before adding (the panel is rebuilt with its Canvas); permanent subscriptions belong in OnInit / OnDispose.
- Coroutines have no per-object host — use Run / Halt / HaltAll from ControllerBase, never StartCoroutine.
